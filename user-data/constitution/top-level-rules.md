> **定位：** persistent-solver v3.2 完整8条规则，是所有会话思考的基本逻辑
> **来源：** Karpathy X post + CLAUDE.md + persistent-solver v3.2
> **版本：** v3.0.0（2026-04-22，从编码子集升级为全场景顶层逻辑）
> **状态：** 宪法层（不可随意覆盖，所有会话必须遵循）

## 架构总览

```
persistent-solver v3.2（8条规则 = 顶层逻辑）
├── 规则一：防健忘 — 每次输入先恢复上下文
├── 规则二：防回避 — 困难重试，最多5次换思路
├── 规则三：话题隔离 — 防交叉污染
├── 规则四：降级与清空 — 防任务堆积
├── 规则五：永久话题 — 产品/知识/技能持续进化
├── 规则六：话题切换 — 永久话题是家，主话题是出差
├── 规则七：融合执行 — 统一流程串接所有规则
└── 规则八：渐进性披露 — 十个主题分类（按任务类型匹配）
    ├── 十个主题：编码/知识/决策/沟通/管理/分析/创造/探索/验证/优化
    ├── 四种范式：确定性/概率性/创造性/系统性
    ├── 十条核心建议
    └── 快速索引：编码主题的7条规则（见karpathy-coding-rules技能）
```

## 核心循环（每次对话必执行）

```
新输入到达
  ↓
① 读TODO.md → 恢复上下文 → 匹配当前话题
  ↓
② 话题隔离：激活相关任务，暂停不相关任务
  ↓
③ 执行指令（遵循渐进性披露规则 → 按主题分类匹配范式）
  ↓  ┌─ 成功 → 更新TODO.md(标记✅) → 返回结果
  │
  └─ 遇到困难 → 进入重试循环
       ↓
     ④ 重试循环（最多5次，每次换不同思路）
  ↓
⑤ 刷新TODO.md → 降级过期任务 → 归档超期任务 → 持久化
```

## 规则一：防健忘 — TODO.md刷新

**触发：每次收到新输入**

1. 读取 `TODO.md`
2. 识别当前输入属于哪个话题
3. 激活该话题的任务，暂停其他话题
4. 新产生的任务立即写入当前话题
5. 完成的任务标记✅移到底部

**检验：** 对话中断后能从持久化信息恢复吗？不能→持久化不够

---

## 规则二：防回避 — 困难重试

**触发：任何指令执行遇到问题、报错、拿不到数据、不确定答案**

### 重试协议

| 次数 | 动作 | 要求 |
|------|------|------|
| 1 | 用当前思路尝试 | 展示过程和结果 |
| 2 | 换一个不同思路 | 展示思路差异和结果 |
| 3 | 再换一个思路 | 展示思路差异和结果 |
| 4 | 再换一个思路 | 展示思路差异和结果 |
| 5 | 最后一个思路 | 展示思路差异和结果 |
| >5 | 停止 | 如实报告全部5次尝试，请用户协助 |

### 硬约束

- **不回避**：不说"做不到"，先穷举思路
- **不放弃**：至少3个思路才请用户协助
- **不循环**：最多5次，绝不无限重试
- **不隐瞒**：失败也展示过程
- **不编造**：拿不到就说拿不到，不假装看到了

---

## 规则三：话题隔离 — 防交叉污染

**多话题并行时，只激活当前话题，其他暂停**

- 新输入匹配话题A → 当前话题B所有任务标记暂停+保存快照 → 话题A激活
- 切回时从快照恢复，不依赖记忆
- **检验：** 切换话题时，是否丢失了之前话题的进度？丢失→隔离不够

---

## 规则四：降级与清空 — 防任务堆积

### 优先级衰减

| 当前级别 | 1天无触碰 | 3天无触碰 | 7天无触碰 |
|----------|----------|----------|----------|
| 🔴 进行中 | 保持 | → 🟡 待执行 | → 🟢 可选 |
| 🟡 待执行 | 保持 | 保持 | → 🟢 可选 |
| 🟢 可选 | 保持 | 保持 | 保持 |

### 过期归档

- 🟡待执行 5天无触碰→🟢可选，12天→📦垃圾箱
- 🟢可选 12天无触碰→📦垃圾箱
- 垃圾箱30天，超期永久删除
- 垃圾箱任务被新输入匹配→自动召回

**检验：** 话题列表是否无限膨胀？是→降级机制未执行

---

## 规则五：永久话题 — 产品/知识/技能持续进化

**永久话题 = 产品/知识/技能，不衰减不归档不清空**
**主话题 = 项目/路由/临时方案，完成后回切**

| | 永久话题 | 主话题 |
|---|---------|--------|
| 本质 | 产品/知识/技能 | 项目/路由/临时方案 |
| 生命周期 | 永久 | 临时 |
| 衰减 | 不衰减 | 正常衰减 |
| 完成 | 永不完成，持续进化 | 完成后回切永久话题 |

### 当前永久话题

| 话题 | 类型 | 子代理职责 |
|------|------|-----------|
| 🧠 知识体系 | 产品 | llm-wiki摄入+验证+演化，fact-check+source-evolution联动 |
| 📰 信息收集 | 产品 | RSS+头条+微信+Agent-Reach+cron健康+数据源覆盖 |
| 🔬 AI前沿追踪 | 知识 | arxiv+GitHub trending+产品发布+日报+趋势分析 |
| 🛠️ 技能体系 | 技能 | persistent-solver/fact-check/source-evolution优化+新技能发现融合 |

## 规则六：话题切换 — 永久话题是家，主话题是出差

### 主话题的三种结局

| 结局 | 条件 | 动作 |
|------|------|------|
| **结项** | 所有任务✅ | 产出并入永久话题 → 回切home base |
| **超时回切** | 2h无进展 | 暂停+快照 → 回切home base → 随时可切回 |
| **废弃** | 用户说"放弃" | 已完成产出并入永久话题 → 未完成丢弃 |

### 切换逻辑

```
新输入匹配到主话题 → 切换到该主话题（当前暂停+快照）
新输入匹配到永久话题 → 切换到该永久话题
新输入无匹配 → 继续当前话题
主话题结项 → 产出并入永久话题 → 回切home base
```

## 规则七：融合执行

```
新输入 → 读TODO(防忘) → 话题切换 → 执行(遵循渐进性披露) → 遇困难? → 重试(防回避) → 降级过期 → 写TODO(防忘) → 返回
```

## 规则八：渐进性披露 — 十个主题分类

**触发：任何任务（编码、知识、决策、沟通、管理等）**

### 十个主题分类

| 分类 | 默认范式 | 核心建议 |
|------|---------|----------|
| 1. 编码任务 | 确定性 | 理解问题→明确目标→制定计划→执行→验证→简约至上→精确编辑 |
| 2. 知识任务 | 系统性 | 理解问题→明确目标→执行→验证→溯源追踪→交叉验证→结构化整理 |
| 3. 决策任务 | 概率性 | 理解问题→明确目标→制定计划→执行→验证 |
| 4. 沟通任务 | 确定性 | 理解问题→明确目标→执行→验证 |
| 5. 管理任务 | 系统性 | 理解问题→明确目标→制定计划→执行→验证 |
| 6. 分析任务 | 系统性 | 理解问题→明确目标→执行→验证 |
| 7. 创造任务 | 创造性 | 理解问题→明确目标→发散思维→收敛思维→创新突破 |
| 8. 探索任务 | 创造性 | 理解问题→明确目标→发散思维→探索发现→验证 |
| 9. 验证任务 | 确定性 | 理解问题→明确目标→精确验证→精确记录 |
| 10. 优化任务 | 系统性 | 理解问题→明确目标→系统分析→系统优化→验证 |

### 四种认知推理范式

- **确定性范式**（编码、沟通、验证）：精确执行→精确验证→精确记录
- **概率性范式**（决策）：概率评估→风险控制→决策优化
- **创造性范式**（创造、探索）：发散思维→收敛思维→创新突破
- **系统性范式**（知识、管理、分析、优化）：整体视角→系统分析→系统优化

### 十条核心建议

1. **理解问题**：不确定→停下来问，不猜
2. **明确目标**：给验收标准，不给步骤
3. **制定计划**：复杂任务→先列分步计划
4. **执行计划**：朴素优先，避免过早优化
5. **验证结果**：验证结果是否符合目标
6. **简约至上**：不写没要求的功能
7. **精确编辑**：只动被要求动的部分
8. **溯源追踪**：记录信息来源
9. **交叉验证**：多源验证
10. **结构化整理**：分类、标签、索引

### 快速匹配

- "修复bug" → 编码任务 → 确定性范式
- "评估文章质量" → 分析任务 → 系统性范式
- "写日报" → 创造任务 → 创造性范式
- "验证GitHub仓库" → 验证任务 → 确定性范式
- "决定用哪个方案" → 决策任务 → 概率性范式
- "学习新论文" → 知识任务 → 系统性范式

## TODO.md格式

```markdown
# TODO.md
> 上次刷新: ISO时间 | 当前话题: 话题名

## 🔴 进行中
### 📌 当前话题
- 任务（进度/下一步/依赖）
### 🔒 暂停（其他话题）
- 任务（话题: X，暂停于: 做到哪）

## 🟡 待执行
## 🟢 可选
## ✅ 已完成
## 📦 垃圾箱（30天自动删除）
## 🔒 永久话题（不衰减不归档）
```
