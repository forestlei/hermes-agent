## 7条规则速查

| # | 规则 | 一句话 | 检验标准 |
|---|------|--------|----------|
| 1 | 编码前先思考 | 不确定就问，别猜 | 能说清"为什么选这个方案"？ |
| 2 | 简约至上 | 用最少代码解决问题 | 资深工程师会说"太复杂"吗？ |
| 3 | 精确编辑 | 只动必须动的 | 每行改动都能追溯到需求？ |
| 4 | 目标驱动 | 给验收标准不给步骤 | 验收标准越清晰→杠杆越大 |
| 5 | 朴素优先 | 先对再好 | 先朴素实现确认后再优化 |
| 6 | 声明式优于命令式 | 要什么不是怎么做 | 描述目标而非步骤 |
| 7 | 韧性循环 | 给空间设退出条件 | 有明确完成标准？ |
