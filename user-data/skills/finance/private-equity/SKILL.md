# Private Equity — 私募股权垂直插件

## PE投资全周期

### 1. 项目发掘（Deal Sourcing）
- 行业聚焦研究
- 财务投资人网络
- 企业家社群
- 并购机会（二手市场）

### 2. 尽职调查（Due Diligence）
- 业务DD（商业模型、竞争格局）
- 财务DD（历史数据、盈利质量）
- 法务DD（合同、诉讼）
- 运营DD（管理层、团队）

### 3. 交易结构（Deal Structure）
- 估值（DCF / Comps / Precedents）
- 股权比例（控股权/少数股权）
- 对赌条款（ratchet / anti-dilution）
- 退出机制

### 4. 投后管理（Portfolio Management）
- 董事会席位
- 财务监控（月度/季度)
- 运营提升（100-day plan）
- 管理团队激励

### 5. 退出（Exit）
- IPO
- 战略出售（Trade Sale）
- 二次收购（Secondary）
- 减资/清算

## 安装的Agent技能
- `pitch-agent` — 投资备忘录（IM）
- `valuation-reviewer` — 投后估值审核
- `statement-auditor` — LP报表审计
- `model-builder` — LBO建模

## 关键指标
- IRR（内部收益率）
- MOIC（资金倍数）
- DPI（已分配倍数）
- TVPI（总价值倍数）
- RVPI（剩余价值倍数）
