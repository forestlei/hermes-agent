# Careful Reasoning — 审慎推理思维守卫

## 概述

这是价值链推理的"质量守卫"技能。在执行 core-thinking 的五步价值链时，每一步都需要经过审慎推理的检查，避免常见认知偏误和逻辑谬误导致的价值误判。

## 核心原则

### 原则 1: 证据先行，结论后置

- **禁止**: 先有结论再找证据（确认偏误）
- **要求**: 先收集证据，再从证据推导结论
- **检验**: 问自己"如果结论相反，现有证据是否也能解释？"— 如果能，结论不够强

### 原则 2: 区分相关性与因果性

- **相关性** ≠ **因果性**: 两个变量同时变化不代表一个导致另一个
- **检验**: 是否存在第三变量（混杂因子）同时影响两者？
- **案例**: AI公司融资额增加 + AI论文数量增加 → 不一定是融资导致论文增多（可能共同受技术突破驱动）

### 原则 3: 量化不确定性

- 每个推断步骤标注置信度：高(≥80%) / 中(50-80%) / 低(<50%)
- **整体置信度 ≤ 最弱环节的置信度**（链条强度取决于最弱环节）
- **禁止**: 用"可能"、"或许"等模糊词替代量化判断

### 原则 4: 主动寻找反面证据

- 对每个价值信号，主动搜索反驳证据
- **确认偏误检查**: 我是否只关注了支持假设的证据？
- **证伪测试**: 什么条件下这个假设会被推翻？
- **反面证据权重**: 如果反面证据强于正面证据，必须修正结论

### 原则 5: 避免过度泛化

- **小样本陷阱**: 2-3次观察不构成模式，至少5次以上才能标记为"模式"
- **幸存者偏差**: 只看成功案例会高估成功率，必须也分析失败案例
- **时间范围**: 短期模式不等于长期趋势，标注时间跨度

## 每步检查清单

### 目标定义阶段

- [ ] 是否混淆了显性目标和隐性目标？
- [ ] 目标分解是否遗漏了关键子目标？
- [ ] 子目标是否真的可独立验证？
- [ ] 是否存在"预设结论"的目标定义？

### 价值模式识别阶段

- [ ] 模式出现次数是否足够（≥5次）？
- [ ] 是否存在更简单的解释（奥卡姆剃刀）？
- [ ] 模式是否可能只是噪音（随机波动）？
- [ ] 模式的时效性如何？是否已过时？

### 价值发现阶段

- [ ] 发现的信号是否有独立证据支撑？
- [ ] 是否受到近因效应影响（近期事件权重过大）？
- [ ] 跨域关联是否有逻辑支撑，还是表面相似？
- [ ] 反共识观点是否有足够证据，还是为反而反？

### 价值链验证阶段

- [ ] 链条每步的置信度是否合理标注？
- [ ] 最弱环节是否识别并标注？
- [ ] 是否考虑了链条的替代路径？
- [ ] 风险评估是否覆盖了尾部风险？

### 价值推荐阶段

- [ ] 推荐排序是否受到锚定效应影响？
- [ ] 个性化适配是否过度拟合用户历史？
- [ ] 推荐通道选择是否与侵入性匹配？
- [ ] 是否设置了追踪机制来验证推荐效果？

## 常见偏误速查

| 偏误 | 表现 | 对策 |
|------|------|------|
| 确认偏误 | 只关注支持假设的证据 | 主动搜索反面证据 |
| 锚定效应 | 过度依赖第一个信息 | 用多个独立起点分析 |
| 近因效应 | 最近事件权重过大 | 拉长时间窗口看趋势 |
| 幸存者偏差 | 只看成功案例 | 主动分析失败案例 |
| 过度自信 | 置信度标注偏高 | 用历史校准数据调整 |
| 从众效应 | 群体观点影响个人判断 | 独立验证后再参考群体 |
| 沉没成本 | 已投入资源影响继续决策 | 零基分析，忽略已投入 |
| 框架效应 | 问题表述影响判断 | 换角度重新表述问题 |

## 降级策略

当审慎推理检查发现问题时：

- **低风险问题** — 标注但继续，在推荐中注明不确定性
- **中风险问题** — 降低置信度，补充证据后重新验证
- **高风险问题** — 暂停推荐，必须修复后才能继续

## 使用时机

- 执行 core-thinking 价值链推理的每一步之后
- 对关键推断结论做最终审查时
- 群聊中出现高度一致的观点时（警惕从众效应）
- 价值推荐即将发出之前
