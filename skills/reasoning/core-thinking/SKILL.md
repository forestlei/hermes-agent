# Core Thinking — L3 价值层思维框架

## 概述

这是 L3 价值层的核心思维技能，定义了从目标到推荐的完整价值链推理模式。当需要深度分析、战略决策、或主动发现价值时激活此技能。

## 五步价值链

### Step 1: 目标定义 (Goal Definition)

在分析任何问题前，先明确目标层级：

- **显性目标** — 用户明确提出的需求（"帮我分析这个行业的趋势"）
- **隐性目标** — 从行为和上下文推断的深层需求（频繁问某类问题 → 持续关注该领域）
- **目标分解** — 将大目标拆解为可验证的子目标（"分析趋势" → 数据采集 → 模式识别 → 预测验证 → 推荐行动）

**检验标准**: 每个子目标必须可独立验证（有明确的完成条件）。

### Step 2: 价值模式识别 (Value Pattern Recognition)

从数据中识别反复出现的价值信号组合：

- **价值信号** — 数据中的机会/风险信号（异常波动、政策变化、技术突破）
- **价值模式** — 反复出现的信号组合（政策+技术→行业拐点；需求+供给→价格窗口）
- **模式匹配** — 新数据匹配已知模式时触发分析
- **模式进化** — 已有模式随环境变化调整参数（通胀期"政策信号"权重提升）

**检验标准**: 模式必须至少被验证过 2 次才能标记为"已确认"。

### Step 3: 价值自动发现 (Value Auto-Discovery)

非问答场景下主动寻找价值信号：

- **主动扫描** — 定期检查信息源，寻找异常信号和新模式
- **跨域关联** — 不同领域交叉产生新价值（AI突破+医疗→数字医疗机会）
- **长尾发现** — 低频信号中的隐藏价值（小众政策、边缘技术）
- **反共识识别** — 与主流观点相反的信号（市场过度悲观/乐观时）

**检验标准**: 发现的价值信号必须有至少一条可追踪的证据链。

### Step 4: 价值链验证 (Value Chain Validation)

对发现的价值构建完整的推理链并验证：

- **价值链构建** — 信号 → 推断 → 行动 → 收益（每步都要有逻辑支撑）
- **链条验证** — 评估每步的置信度（高/中/低）
- **风险评估** — 链条断裂的可能性和后果
- **链条分级** — 按整体置信度分级（高置信:所有步骤≥中; 中置信:1步低; 低置信:≥2步低）

**检验标准**: 价值链必须包含至少3个环节，每环节有独立证据支撑。

### Step 5: 价值推荐 (Value Recommendation)

将验证通过的价值推荐给用户：

- **推荐排序** — 期望价值 × 置信度 × 用户偏好，综合排序
- **个性化适配** — 按用户角色/兴趣/风险偏好筛选
- **推荐呈现** — 四种通道（见下表）
- **推荐追踪** — 推荐→查看→行动→结果，闭环反馈
- **推荐进化** — 高转化推荐强化，低转化降权或调整呈现方式

| 通道 | 触发条件 | 典型场景 | 侵入性 |
|------|---------|---------|--------|
| 紧急告警 | 高置信度 + 高时效性 | 突发政策变化影响持仓 | 高（主动推送+@用户） |
| 日报嵌入 | 中置信度 + 时效性适中 | 趋势信号写入次日日报 | 中（随日报一起） |
| 定期推送 | 低时效性 + 需长期观察 | 月度价值模式汇总 | 低（周期性推送） |
| 被动响应 | 用户主动查询时附加 | 用户问某行业时推荐关联价值链 | 最低（不主动打扰） |

## 推荐追踪闭环

```
推荐发出 → 用户是否查看(打开/点击) → 是否行动(采纳建议) → 结果如何(正/负反馈)
    │                                    │                       │
    ▼                                    ▼                       ▼
 未查看→调整通道/呈现                未行动→降低置信度/调整话术   正反馈→强化该推荐模式
 或降低推送优先级                   或补充论据                  负反馈→降权/暂停该类推荐
```

## L3 进化指标

| 指标 | 衡量 | 目标 |
|------|------|------|
| 价值发现率 | 主动发现的有效信号数/周期 | ≥1/天 |
| 模式命中率 | 匹配的模式后续被证实的比率 | ≥40% |
| 价值链完整度 | 推荐的价值链可完整追踪的比率 | ≥60% |
| 推荐到达率 | 验证通过的价值链成功推荐给用户的比率 | ≥90% |
| 推荐查看率 | 用户实际查看推荐内容的比率 | ≥50% |
| 行动转化率 | 价值推荐导致用户行动的比率 | ≥20% |
| 推荐进化率 | 推荐策略因反馈调整的频率 | ≥1次/周 |

## 层级关系

```
L3 价值层 ←──需求反哺──→ L1 数据层
▲     │                   │
│     └─反馈反哺─→ L2 能力层
│                         │
│                         ▼
└──────── L2 能力层 ────────┘

L1 是 L2 基础: 没有可信数据，分析逻辑无意义
L2 是 L3 基础: 没有分析能力，价值发现是空中楼阁
L3 是输出层: 发现并验证的价值必须推荐给用户才能形成闭环
L3 反哺 L1: 价值发现揭示新信息源需求 → L1 扩展采集
L3 反哺 L2: 推荐追踪反馈 → L2 逻辑参数调优
```

## 使用时机

- 用户要求深度分析或战略判断时
- 需要从数据中主动发现价值时
- 需要构建推理链并验证时
- 需要对推荐进行排序和追踪时
- 群聊中多人讨论产生新洞察时
